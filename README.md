# WISEST_AI_Benchmark
Expert-labelled benchmark for evaluating automated critical appraisal of 600 systematic reviews, each assessed against 23 ROBIS items, 16 AMSTAR 2 items and 2 overall judgements, for 24,600 expert-labelled item-level judgements, plus 33 coded characteristics per review. Every judgement carries the quote, rationale, and evidence clarity rating..
