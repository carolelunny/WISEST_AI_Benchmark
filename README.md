# WISEST_AI_Benchmark
Expert-labelled benchmark for evaluating automated critical appraisal of 600 systematic reviews, each assessed against 23 ROBIS items, 16 AMSTAR 2 items and 2 overall judgements, for 24,600 expert-labelled item-level judgements, plus 33 coded characteristics per review. Each judgement includes supporting source evidence, a written rationale, and an assessment of whether the evidence was clear, vague, or conflicting.

## Earlier release
An earlier release, called WISEST-QA-Dataset, of 150-reviews and associated code are available at https://github.com/carolelunny/WISEST-QA-Dataset/

## Research applications
The WISEST AI Benchmark was designed to support research into the accuracy, validity, evidence traceability, and reliability of automated critical appraisal.

## Data availability
The full annotated dataset is not publicly released through this repository. Documentation and synthetic examples can be shared separately.
