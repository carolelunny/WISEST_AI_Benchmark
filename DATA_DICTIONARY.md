# Public-facing data dictionary (illustrative schema)

This dictionary describes a **demonstration structure**, not a verified export of the production WISEST database. Confirm exact source variable names and allowed values before publication.

| Field | Description |
|---|---|
| `review_id` | Fictional or anonymized identifier |
| `review_characteristics` | Placeholder object for 33 coded review characteristics (actual variable definitions to be documented) |
| `judgements` | Array of appraisal judgements |
| `instrument` | ROBIS / AMSTAR2 / OVERALL |
| `item_id` | Item identifier defined by the instrument |
| `expert_label` | Expert assessment; scale depends on instrument/item |
| `source_quote` | Supporting quotation (fictional in example only) |
| `rationale` | Written rationale |
| `evidence_clarity` | clear / vague / conflicting |

The example includes only a few demonstration judgements rather than all 41; it is not a completeness test.
