# Publish this documentation-only repository on GitHub

1. Visit https://github.com/carolelunny and sign in.
2. Click **New repository** (or the plus menu → **New repository**). Name it `WISEST-benchmark`, choose **Public**, and create it.
3. On the repository page, use **Add file → Upload files** to upload `README.md`, `DATA_DICTIONARY.md`, `ACCESS_AND_LIMITATIONS.md`, and the `data/` folder contents. Preserve the `data/synthetic_example.json` path; GitHub supports dragging a local folder into Upload files.
4. Commit changes. GitHub automatically renders the root `README.md` on the repository front page. Click `data/synthetic_example.json` to show the clearly fictional example.
5. From your profile page, pin `WISEST-benchmark` (Customize your pins), so hiring managers see it immediately.
6. Optionally create a separate **public** repository named `carolelunny` containing a `README.md`; that README then appears on your GitHub profile. Add a link to `WISEST-benchmark` there. Do not place WISEST records in that profile repository.
7. Add the published repository URL to your BlueDot work-sample index, CV, LinkedIn and research presentations.

**Before uploading:** review file contents, author credit, source permissions, publication embargoes, and any sensitive information. This starter package does not include the real dataset.
